Консольная СУБД с поддержкой CRUD-операций.

## Возможности

- Создание, удаление и просмотр таблиц
- Поддержка типов данных: `int`, `str`, `bool`
- CRUD-операции (Create, Read, Update, Delete)
- Хранение метаданных в JSON формате
- Красивый вывод таблиц через PrettyTable

## Управление таблицами

Доступные команды:

- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создать таблицу (автоматически добавляется `ID:int`)
- `drop_table <имя_таблицы>` — удалить таблицу
- `list_tables` — показать список всех таблиц
- `info <имя_таблицы>` — информация о таблице

**Поддерживаемые типы данных:** `int`, `str`, `bool`

### Пример работы с таблицами

```bash
# Создание таблицы
create_table users name:str age:int is_active:bool

# Список таблиц
list_tables

# Информация о таблице
info users

# Удаление таблицы
drop_table users
```

## CRUD-операции

Доступные команды:

- `insert into <таблица> values (<значение1>, <значение2>, ...)` — добавить запись

- `select from <таблица>` — выбрать все записи

- `select from <таблица> where <условие>` — выбрать записи по условию

- `update <таблица> set <столбец>=<значение> where <условие>` — обновить записи

- `delete from <таблица> where <условие>` — удалить записи

### Примеры CRUD-операций

```bash
# Добавление записи
insert into users values ("Артём", 26, true)
insert into users values ("Мария", 24, false)

# Выборка всех записей
select from users

# Выборка с условием
select from users where age = 26
select from users where is_active = true

# Обновление записи
update users set age = 27 where name = "Артём"

# Удаление записи
delete from users where name = "Мария"
```



## Установка
### Требования

    Python 3.12+

    Poetry 1.2.0+

### Установка через Poetry

```bash
# Клонирование репозитория
git clone <ваш-репозиторий>
cd project2-bogdanov-artem-m25-555

# Установка зависимостей
poetry install

# Запуск приложения
poetry run project
```



### Обработка ошибок

    Таблица уже существует — при попытке создать таблицу с существующим именем

    Таблица не существует — при операциях с несуществующей таблицей

    Неверный тип данных — при несоответствии типов

    Неверное количество аргументов — при некорректном вызове команд

    PrettyTable — форматированный вывод таблиц
